# BIMToolkit 快速上手（pyRevit 扩展）

一份给新人或"很久没碰"时的速查。细节在 [README.md](README.md)，这里只讲怎么跑起来、怎么用。

## 0. 环境
- Windows + **Revit 2019** + **pyRevit 6.5.5**（自带 IronPython 2.7 引擎，脚本就跑在这上面）
- 本机校验 / 部署用的 Python（不在 Revit 里）：`E:\AI-pyenvs\bim-dev\Scripts\python.exe`

## 1. 安装 / 更新
```bash
E:\AI-pyenvs\bim-dev\Scripts\python.exe deploy.py          # 正式部署
E:\AI-pyenvs\bim-dev\Scripts\python.exe deploy.py --dry    # 只看计划、不写盘
E:\AI-pyenvs\bim-dev\Scripts\python.exe deploy.py --no-tag # 不打 git 标签
```
- 自动：部署前备份当前已装版到 `last-good/<时间戳>/` → `robocopy /MIR` 把 `BIMToolkit.extension` 镜像到
  `%APPDATA%\pyRevit\Extensions\BIMToolkit.extension` → 写 `version.txt` → 仓库有提交则打 `deploy-<时间戳>` 标签。
- 手动也行：把 `BIMToolkit.extension` 整目录拷到上面的 Extensions 目录覆盖。
- **生效**：重启 Revit（或 pyRevit → Reload）。选项卡里出现 **BIMToolkit → BIM 工具** 面板。

## 2. 面板不出现？每次开 Revit 弹 Xceed 报错
现象：`未能加载文件或程序集 Xceed.Wpf.AvalonDock, Version=2.0.19.10`。这是 pyRevit 安装包打包缺陷，不正常但已知。
处理：先双击 `fix_pyrevit_dll.bat`（只读检测，报告缺在哪几个引擎目录），再自己取一份 2.0.19.10 的
该 dll 交给脚本：`fix_pyrevit_dll.bat "<那份 dll 的完整路径>"`。**仓库不内置这颗第三方 dll**
（缘由与校验值见 `tools\README.md`）；脚本会核对版本号，已在位的文件不动，先加 `/dry` 可只看会写到哪。
看到 `[ALL OK]` 后重启 Revit。

## 3. 七个按钮怎么用（推荐工作流）
1. **一键统计** —— 先看模型体量（构件/楼层/视图/图纸/族/警告）。
2. **BIM 体检** —— 只读体检：警告/错误、族、参数化深度、综合健康分(A/B/C/D) + 整改建议。扫描出错会显式 ⚠️，不再静默成 0。
3. **批量改参** —— 按 `批量改参.pushbutton/batch_params.csv` 批量改参数。**默认只预览**「原值→新值」，确认框点「确定」才事务写入（Revit 可 Ctrl+Z 撤销）。
4. **构件清单导出** —— 导出全部构件 CSV/JSON/MD（ElementId/类别/族类型/楼层/名称），是 4D 关联底表。
5. **进度关联** —— 阶段5：填 `进度关联.pushbutton/schedule_summary.csv`（uid/名称/楼层/类别/类型/计划开始/计划完成/状态），看任务↔构件**覆盖率**、缺漏任务、游离构件（只读）。
6. **楼层清点** —— 按楼层统计构件数（只读）。
7. **DWG翻模** —— 先把 DWG 用 `dwg_to_json.py` 转成 `model_plan.json`，再点此按钮选 JSON → 预览计划（各类型数量 + 未匹配）→ 确认才写（轴网/墙/柱成熟；门/窗/房/板实验性，梁跳过）。

## 4. 两个 CSV 模板（直接改就行）
- `批量改参.pushbutton/batch_params.csv` —— 列：`Category,Type,ParamName,Value`
- `进度关联.pushbutton/schedule_summary.csv` —— 列：`uid,名称,楼层,类别,类型,计划开始,计划完成,状态`
（楼层/类别/类型留空 = 任意；类型按「族:类型」子串匹配）

## 6. 常见坑
- 批量改参**只扫实例参数**（非类型参数）；某行 0 匹配多半是 Category/Type/ParamName 拼写或参数类型不对。
- IronPython 2.7 下 `open(encoding=)` / `collector.Count` / 直接 `list(collector)` 在真机会崩 —— 已用 `lib/bimlib.py` 兼容 helper 规避，自己加代码时注意。
- **引擎决策**：保持 **IronPython 2.7**，**不切 CPython3**（2026-09-04 评估）。CPython 引擎对 `pyrevit.forms`/WPF 仅 1 星支持，而 5/7 按钮依赖 `forms`（含批量改参的确认写入闸门、DWG翻模 的选文件+确认写入）；本机也无 CPython 引擎/`pythonnet`；且代码已引擎无关，「去兼容层」无收益。若某按钮将来真要现代 Python 库，只给那一按钮加 `#! python3` 并改 `forms`→`output`（局部切）。
