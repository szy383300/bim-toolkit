# BIMToolkit 面试演示脚本

> 预计时长：15-20 分钟 | 适用场景：求职面试 / 作品集展示

---

## 演示前准备

1. 打开 Revit 2019，加载一个测试项目（建议用自带样例 `rac_advanced_sample_project.rvt` 或自建简单别墅）
2. 确保 pyRevit 已加载，BIMToolkit tab 可见
3. 准备 DeepSeek API Key（已配置在 `lib/deepseek_config.json`）
4. 关闭其他无关软件，保持桌面整洁

---

## 演示流程

### 第一部分：项目介绍（2 分钟）

**话术要点**：
- "这是我独立开发的 Revit 插件，将 AI 大模型能力集成到 BIM 工作流"
- "覆盖从图纸识别到自动出图的全链路，17 个功能按钮"
- "与商业产品（如广联达 CONCETTO）的差异化：本地部署、支持旧版 Revit、开放架构"

**展示**：
- 打开 `README.md`，快速浏览功能架构图
- 指向 BIMToolkit tab，展示两个 panel 的按钮布局

---

### 第二部分：核心功能演示（10 分钟）

#### 1. AI 指令（自然语言操控 Revit）— 3 分钟

**演示步骤**：
1. 点击 **AI 指令** 按钮
2. 输入："把所有标高 1 的墙厚度改成 200mm"
3. 展示 Notepad 预览窗口（AI 生成的代码）
4. 点击确认执行
5. 展示墙厚度变化结果

**技术亮点**：
- "DeepSeek API + 自愈重试机制，最多 3 轮自动修正"
- "安全门设计：代码先预览再执行，防止误操作"
- "抓取模型上下文（构件数/类别/标高）作为 prompt 输入"

**可能的问题**：
- API 调用失败 → 展示错误处理和重试逻辑
- 代码生成不准确 → 展示回喂修正机制

---

#### 2. 一键建模（参数化生成）— 2 分钟

**演示步骤**：
1. 打开 `lib/building_params.json`，展示参数结构
2. 点击 **一键建模** 按钮
3. 展示自动创建过程：标高 → 墙 → 板 → 屋顶 → 门窗
4. 3D 视图展示生成的别墅模型

**技术亮点**：
- "JSON 参数驱动，修改参数即可生成不同方案"
- "每步独立 Transaction，失败可回滚"
- "处理了 Wall.Create 重载歧义、幕墙/叠层墙等边界情况"

---

#### 3. 规范审查（5 维评分）— 2 分钟

**演示步骤**：
1. 点击 **规范审查** 按钮
2. 展示 5 类检查过程（消防/抗震/结构/面积/节能）
3. 展示评分结果和等级（优秀/良好/及格/需整改）
4. 点开详细报告，展示具体不符合项

**技术亮点**：
- "基于国标阈值（GB50016/GB50011/GB50010 等）"
- "加权评分体系，0-100 分量化模型质量"
- "可扩展：企业可导入自有规范库"

---

#### 4. 智能出图（视图自动化）— 2 分钟

**演示步骤**：
1. 点击 **智能出图** 按钮
2. 展示平面图创建结果（3 个楼层平面图）
3. 说明立面图限制："Revit 2019 + IronPython 2.7 的 API 兼容性问题，已降级处理"
4. 在项目浏览器中展示生成的视图

**技术亮点**：
- "主动降级而非崩溃：API 不可用时提示用户手动操作"
- "踩坑记录完整：尝试了 5 种方案，记录了每种失败原因"
- "升级至 CPython3 或 Revit 2022+ 可解决"

---

#### 5. 工程量统计 + 施工方案 — 1 分钟（快速展示）

**演示步骤**：
1. 点击 **工程量统计**，展示混凝土/模板/钢筋清单和造价
2. 点击 **施工方案**，展示 7 阶段方案生成

**技术亮点**：
- "工程量自动计算 + 造价估算（已修复单位转换 bug）"
- "施工方案包含工期/设备/质量检查点"

---

### 第三部分：技术深度（3 分钟）

**展示 README 中的"关键踩坑记录"**：

1. **IronPython 2.7 无 f-string** → 全部用 `%` 或 `.format()`
2. **unicode 拼接炸弹** → 统一 `to_text()` 转 unicode
3. **Wall.Create 重载歧义** → 必须用 8 参重载
4. **ViewSection API 不可用** → 5 种尝试 + 降级方案

**话术要点**：
- "这些踩坑记录体现了我的问题解决能力和文档习惯"
- "每个问题都记录了原因、解决方案、影响范围"

### 第五部分：Q&A 准备（3 分钟）

**常见问题**：

1. **Q: 为什么选 pyRevit 而不是 Revit 原生插件（C#）？**
   - A: "pyRevit 开发效率高，适合快速原型；IronPython 2.7 兼容旧版 Revit（国内企业大量使用）；CPython3 引擎可无缝迁移"

2. **Q: AI 生成的代码安全吗？**
   - A: "有安全门设计：代码先预览再执行；Transaction 包裹，失败自动回滚；最多 3 轮重试防止无限循环"

3. **Q: 规范审查的阈值从哪来？**
   - A: "基于国标（GB50016/GB50011 等）；`standards_quick.json` 存储阈值；企业可导入自有规范库"

4. **Q: 立面图为什么没做出来？**
   - A: "Revit 2019 + IronPython 2.7 的 ViewSection API 有兼容性 bug，尝试了 5 种方案都失败。这是环境限制，不是设计问题。升级引擎或 Revit 版本可解决"

5. **Q: 这个项目多少人做的？**
   - A: "独立开发，从架构设计到代码实现全部原创。README 最后一行写了"
