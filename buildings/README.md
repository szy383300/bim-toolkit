# buildings/ —— 这些配方是什么，素材从哪来

## 一句话

这里是 **genbuild 引擎的输入配方**（7 份 YAML + 1 份 params.json + 1 份生成脚本），每份描述一栋楼的层数、柱网、
墙厚、门窗洞口和标高。它们是我练手用的**重建练习**，不是任何项目的交付物。

## 素材来源（说清楚，不含糊）

- 参考图（效果图 / 平面图 / 施工图）是 2026 年上半年从**公开网络渠道**收集的练习素材，
  其中含批量下载的建筑施工图合集。**原始发布者与出处如今已无法追溯**——我没法在这里给出链接，
  因为确实找不到了。
- 文件里沿用的名称（仙湖别墅、北馨 05、云弦塔、三层社区服务中心、四层白色建筑……）是**素材自带的叫法**，
  不是我起的，也不代表它们对应某个真实在建工程。`云弦塔` 那份例外：它是我按一张效果图自己设定的
  假想楼（17 层、南侧逐层收退），设计意图写在它的 `note:` 里。
- **YAML 里的数字是我自己反推的**：从参考图上的标注和常见取值推层高、柱网、墙厚、洞口尺寸。
  原设计的著作权不属于我，我也不对这些建筑的外观或设计主张任何所有权。
- 产出是几何骨架。`DWG翻模` 那条流水线只建墙 / 楼板 / 门 / 窗 / 楼梯，**不建屋面**
  （这件事在 `../docs/用已有模型代替手工样板-屋面库.md` 里踩过并写了记录）。

## 用之前要改的两处

配方里有 per-machine 的绝对路径，公开版**保持了我自己机器上的原值**，直接跑会指向不存在的目录：

| 字段 | 含义 | 你要做什么 |
|---|---|---|
| `save_path` | 建模完成后另存的位置 | 改成你机器上的目录。父目录不存在时 `spec.py` 会给警告 |
| `json_path`（仅 `北馨05.yaml`） | DWG→JSON 的中间产物位置 | 自己跑一遍翻模，或删掉该字段改用默认 |
