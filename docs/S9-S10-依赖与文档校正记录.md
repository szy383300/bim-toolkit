### S10b：`BRIDGE_VERSION` 统一

**改前**：`bridge_core.py:210` 写 `BRIDGE_VERSION = "7.11.0"`，
而同一个文件里已经积累了 **v7.12.0 / 7.12.1 / 7.12.2 / 7.12.3 / 7.12.4** 五轮修复注释
（多数是 2026-09-28 端到端评测实测出的 2019 API 适配）。

**为什么这个必须改**：`ping` 命令会回报 `BRIDGE_VERSION`，它是判断
"Revit 里正跑着的桥，是不是仓库里最新那份"的**唯一凭据**。
低报 5 个补丁，等于在最需要它准确的地方说假话 —— 而这正是本项目的头号教训
（§3.4 的部署漂移就是"看起来是新的，其实是旧的"）。

**改后**：`BRIDGE_VERSION = "7.12.4"`，并加注释说明递增约定与这次修正的原因。
