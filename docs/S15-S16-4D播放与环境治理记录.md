# S15 —— 4D 播放

## 一、缺的到底是哪一环

动手前先摸清了现状：**播放这件事桥里已经有了**，而且做得不差 ——
`bridge_core` 的"导览步骤机"（v7.11，借鉴广联达 StepBase：隔离 + 取景 + 导图）：

| 命令 | 作用 |
|---|---|
| `list_steps` | 读导览任务树 JSON，列出步骤 |
| `apply_step` | 按 `levels` 隔离构件 + `ZoomAndCenterRectangle` 取景 |
| `export_view` | 把当前视图导成 JPG |

`_models/guide_steps/step_01.jpg … step_09.jpg` 就是上次跑出来的帧。

**缺的只有一步：把施工进度翻译成这个任务树。**

```
schedule_summary.csv ──[本次新增]──> 4d_steps.json ──[桥]──> frames/step_NN.jpg
```

## 二、生成器（`lib/schedule_to_steps.py`）

输入就是 `进度关联` 按钮已经在用的 `schedule_summary.csv`
（`uid,名称,楼层,类别,类型,计划开始,计划完成,状态`）。

| 设计 | 说明 |
|---|---|
| 步骤格式 | 对齐 `do_list_steps`：`{task, model, note, steps:[{n,title,levels,show_all,desc}]}` |
| 首尾固定 | 第 1 步「全楼总览」、末步「竣工全貌」（沿用仓库既有 `guide_tasktree53.json` 的惯例） |
| 排序 | **按 `计划开始` 排序**（无日期的排最后，再按 uid）—— 4D 的前提就是时间序 |
| 分组 | `task` 每任务一步 / `month` 按开始月合步 / `auto` 超阈值自动按月 |
| `desc` | 日期区间 + 任务明细 + **模型匹配构件数**（复用进度关联的覆盖率结果，让每步可读） |

### 能力边界（重要）

`apply_step` **只能按标高隔离**。而模板里就有「全楼通用墙」这种 `楼层` 为空的任务 ——
这类**无法按楼层隔离**。处理方式是**显式退化 + 显式告警**，而不是静默跳过：

- 该步退化为 `show_all`（全楼显示）
- 标题加前缀「（全楼）」——**否则 4D 动画里会突兀跳回全貌，看的人只会以为程序坏了**
- 返回值里给 warning，按钮上打印出来

## 三、播放器（`mcp/play_4d.py`）

复用 `genbuild.bridge.BridgeClient`（token 定位与认证都是现成的）。

```bash
<python> mcp/play_4d.py 4d_steps.json --out frames
<python> mcp/play_4d.py 4d_steps.json --dry        # 只列步骤，不碰 Revit
<python> mcp/play_4d.py 4d_steps.json --start 3 --end 6 --sleep 1.5
```

每步：`apply_step` → `export_view` → `frames/step_NN.jpg`；跑完打印 ffmpeg 拼动画的命令。

## 四、一个刻意选择：输出**不写按钮目录**

按钮目录是**部署产物** —— 下次 `deploy.py` 的 `/MIR` 会把它删掉
（排除表只保护 `bridge.token` / 审计日志那几个）。
所以 4D 步骤文件写到 `~/Documents/BIMToolkit/4d_steps.json`，部署不影响。

**收敛前先让碎片可见、可验收**，这是能在仓库内做完且有价值的那一半；

## 三、本地 CI

**加 GitHub Actions 没有意义**：仓库 `git remote -v` 是空的，托管 CI 根本跑不起来。

所以交付 **`tools/ci.ps1`** —— 一条命令跑完全部门禁，任一失败即非零退出：

| 关 | 内容 |
|---|---|
| 1 | 解释器 / 依赖契约（`tools/check_env.py`） |
| 2 | 扩展自检 `--strict`（8 关） |
| 3 | 4D 播放器契约（`play_4d.py --dry`） |

```
[CI] PASS -- all gates green     exit=0
```

**失败路径也验过**（一个永远通过的 CI 没有价值）：

```
[NEG] OK   -> good gate
[NEG] FAIL -> bad gate
[NEG] Failed=1     exit=1
```

脚本刻意写成 **ASCII-only**：仓库里 `.bat` 受 cmd 的 GBK 码页坑、
`.ps1` 又要求 UTF-8 带 BOM —— 纯 ASCII 把两个坑都绕开。

> 加 remote 是**你的决定**（要账号/仓库）。加了之后把 `ci.ps1` 接进 CI job 即可，
> 不必重复定义门禁。
