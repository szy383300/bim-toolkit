**改动 1：`pyrevit-bim-panel/deploy.py`（+85 / −6）**

- 新增 `[2b]` 步骤：`_harden_token_acl()`

排除表：

```

```

**改动 2：`bimtoolkit-release/install.bat`（+13 / −2）**

### S6 —— token ACL

**改动前**（`bridge.token` 上有 5 条继承 ACE）：

```
%COMPUTERNAME%\CodexSandboxUsers                  Modify, Synchronize   (继承)
S-1-5-21-2519180448-...-2853556359                 Modify, Synchronize   (继承)
NT AUTHORITY\SYSTEM                                FullControl           (继承)
BUILTIN\Administrators                             FullControl           (继承)
%COMPUTERNAME%\%USERNAME%                         FullControl           (继承)
```

**改动后**：

```
%COMPUTERNAME%\%USERNAME%                         Read, Synchronize     (非继承)
```

命令：`icacls <token> /inheritance:r /grant:r "%USERNAME%:(R)"`

同时在 `deploy.py` 加了 `_harden_token_acl()`，**每次部署后自动重申**。

> ⚠️ 残留：桥在 `load_or_create_token()`（`bridge_core.py:260-272`）新建 token 时
> **不会**自带 ACL。若 `bridge.token` 被删（例如手动清理）后桥重启，会生成一个
> 权限宽松的新文件，需再跑一次 `deploy.py`。根治要改 `bridge_core.py`，
> 但项目有"桥冻结"约定，故留到 S12。
