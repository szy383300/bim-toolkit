## 0. 一句话

真实重复不在按钮层，而在几何原语层：同一套 `Wall.Create` 被写了 5~7 遍。所以收敛的对象是"构件工厂 + 执行通道"，不是"把看起来像的按钮合并"。按钮从 19 减到 8，是这件事的副产品。

> **撤回一条本文早期版本的头号结论（2026-10-07 真机证伪）。**
> 「`bimlib.py` 的 `ElementIsElementTypeFilter(True)` 布尔写反，导致 7 个按钮把族类型当构件」
> 是**错的**：该参数是 `invert`，`True` = 只放行实例（实测 `Filter(True)` 18 堵墙 ==
> `WhereElementIsNotElementType()` 18；`Filter(False)` 35 个 `WallType`）。
> 因此连带作废三条派生结论：`楼层清点` 渲染空表、`批量改参` 写到 WallType、
> `一键统计` 是坏的（它只是与 `BIM 体检` 冗余）。
> 详见 `docs/改动清单-0a-0b.md` 开头的撤回块与 commit `6907584`。
> 本文件的 8 入口划分不受影响——它依赖的是"点下去有没有真东西"，不是那条极性推断。

## 4. 入口 8「AI 建模通道」的具体形态

1. **AI 指令不再产 raw Python，改产 plan**——一串类型化命令，走与 Bridge 同一个 `COMMAND_HANDLERS` 分发点（`bridge_core.py:2339`）。raw `exec` 降为显式兜底 + 逐段确认 + 收窄命名空间。
2. **Bridge 补三个通用放样动词**：`create_family_instance_on_point` / `_on_line` / `_on_surface`。依据：`genbuild/engine.py:95` 自述"墙型定型/面层/验收在桥里没有对应命令，因此**必须** execute_code"——**是缺动词，不是缺权限**。
3. **统一确认门 + 审计**：Bridge 写命令补人工确认（现仅 `AI 指令` 有）；`audit` 补 `sha256(payload)+长度`（现 957 条里 0 条记内容，其中 `execute_code` 269 次）。
4. **`policy` 降回 `build`**；`bridge.token` 比较改 `hmac.compare_digest`（`:2708`）；`_safe_path()` 限根目录（`:1276-1290`、`:2320-2336` 现接受任意路径，UNC 还会逼 Revit 发 SMB 认证）；`save_document` 加"目标已存在需显式 overwrite"（`:2071-2092`）；`shutdown` 进策略与审计（`:2572-2574` 现在闸门之前返回，零留痕）。
5. **稳定性**（已被实证过一次）：`log()` 内 `print(msg)`（`:256`）抛 `SystemError` 把泵打死（`mcp_crash.log` 有完整 traceback）；`recv WSAEINVAL` 无重试上限致死 socket 不回收（运行日志 43,897 行里 16,354 行、约 15 个 fd）；日志无轮转（已 2.49 MB）。

**已核验的安全事实**：`bridge_core.py:230` 代码内置默认是 `{"allow_execute_code": False, "policy": "build"}`，`load_config()` 兜底同样保守——**代码默认方向正确**。风险来自部署副本里持久化的 `mcp_bridge_config.json:6-7` 写成 `dev/true`（其配置注释自陈原因：genbuild 配方需 17 处 execute_code）。

**已实测的攻击面**：`ai_code_guard.py:37-39` 只匹配 import 语句，而 `AI 指令/script.py:14-16` 已在模块顶层 `import os, sys, traceback`，`:430` 又 `ns = dict(globals())` → 我实跑 `ai_code_guard.scan` 的 7 个攻击样本**全部放行**（`os.system` / `os.environ[KEY]` / `os.remove` / `getattr` 拼名 / `importlib` / `clr.AddReferenceWithOptions` / `file()` 内建），对照组正常 Revit 代码 **0 误伤**。另 `AI 指令:352-354` 的 `except Exception: pass` 使护栏 **fail-open**。

## 7. 三条红线

| 测试 | 实情 |

**病根**：`返回值用"无 error 即成功"、异常用 `except: continue/pass`、扣分用恒零表达式`。这一类错误在 §0a、`bimhealth` 整数除法、`standards_checker` 恒 0 条检查给 95 分、`set_material` 无事务却返回 `ok:true`、`install.bat` 判据测目标目录 这五处完全同构。**只有把真断言补进 gate（阶段 6+§10），才不会在收敛后重新长出来。**
